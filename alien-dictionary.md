# Zib Zib Alien Language Dictionary (English)

Source: fan-made "alien language" meme dictionary (originally found as a Spanish-language
word list / generator output), translated to English. Alien code words are unchanged from
the original. A few entries were illegible in the source image (OCR issues) and are marked
"unclear".

No single canonical version of this meme dictionary exists — it's an organic internet trend
with multiple variant lists. This is the fullest version collected so far.

## Notes for the @zibzibx bio/banner project
- "Continue" (tur tur nom), "Begin" (nom tur), "End" (tur nom), "Wait" (tur vop) and
  "Tomorrow" (zup zep) are the real translations to use for a "to be continued" style hint,
  rather than improvised combinations.
- "Happy" = zib zib — direct match with the handle, worth using in bio copy.
